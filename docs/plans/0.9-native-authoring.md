# v0.9 Native Authoring

Status: implemented and verified on disposable Ghost 5 and Ghost 6 instances; not yet published.

## Scope

Extend the existing `create_drafts` and `create_page_drafts` native-block input with lists, quotes, code blocks, image cards, bookmarks, and inline bold, italic, code, and HTTP(S) links. Both tools continue to force Ghost draft status.

Image cards reuse the existing `upload_image` boundary: `src` must exactly match a URL returned by that server instance during the current session. Bookmark metadata is explicit input and the server never fetches the target URL.

## Non-goals

No new MCP tools, arbitrary CRUD, deletion, member or newsletter operations, general Ghost API dispatcher, remote asset fetching, or arbitrary Lexical payloads.

## Release gate

- Completed: unit and MCP schema tests cover all new nodes, inline format bits, unsafe URLs, and the upload-session requirement.
- Completed: disposable Ghost 5 and Ghost 6 integrations create, read back, and preserve every new node.
- Pending publication: package, Registry metadata, README release status, and GitHub Release move to `0.9.0` together.
