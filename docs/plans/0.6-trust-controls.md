# v0.6 Trust Controls

Status: released in v0.6.0 on 2026-08-02.

v0.6 replaces all direct post/Page update tools with a two-step change-set boundary:

1. `preview_changes` reads exact revisions and returns full before snapshots, content impact, protected Lexical nodes, required scopes, and a site-bound HMAC.
2. `apply_change_set` re-reads the batch, verifies the unchanged patch, revisions, effects, HMAC, and exact scopes before writing sequentially with `save_revision=true`.

The server stores no preview or snapshot state. A stale target stops the whole batch before any edit. A remote failure after writing begins can leave a partial result; remaining targets are not attempted. Each result includes a redacted receipt and Ghost readback status.

`replace_body` accepts draft posts/Pages only and is blocked when Lexical contains any rich, media, HTML, embed, or unknown node. Published content accepts bounded metadata fields only.

Permission profiles expose only their defined tool surface: `read-only`, `draft-editor`, `scheduler`, and `publisher`. `GHOST_READ_ONLY` remains a mutually exclusive backward-compatible alias.

Automatic revision restore is not promised because Ghost has no documented stable integration endpoint for it. Recovery uses the returned snapshot and Ghost Admin revision history with a separately previewed reverse change.
